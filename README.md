# DATE Plugin for OSSIM: Python Implementation

This project brings the [DATE (Digital Automatic Terrain Extractor) plugin](https://github.com/martidi/opencv_dsm/tree/imageStack) for OSSIM back to life. It uses pybind11 to be able to still rely on OSSIM for geomatic operations in Python. 

Check date/command.txt to run the Python code. To regenerate the .so file for pyossim, check pyossim/command.txt.
